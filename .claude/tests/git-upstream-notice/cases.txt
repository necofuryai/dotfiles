# Cases for dot_claude/hooks/executable_git-upstream-notice.sh.
# Format: <expect>::<must contain>::<must not contain>::<hook input JSON>
#   expect      notice = prints additionalContext for the input's event
#               silent = prints nothing
#   must ...    substring of additionalContext, or - for no check
# <HERE> in the JSON becomes this directory. Every case must exit 0.
#
# Shapes follow Claude Code 2.1.289 and git 2.56.0: on success git's stderr
# arrives merged into tool_response.stdout, and tool_response.stderr carries
# Claude Code's own notes such as the sandbox_violations block; on failure the
# merged output is in `error` after "Exit code N". Hint lines are what git
# really prints (<remote>/refs/heads/<branch>).
